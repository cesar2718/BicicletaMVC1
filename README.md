
# BicicletaMVC1 - Bike Rental Management System

A web application built with ASP.NET Core MVC for managing a bike rental service. Developed as part of my portfolio to demonstrate CRUD operations, MVC architecture and database management.

### 🚀 Tech Stack
- C# / .NET 8
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server / LocalDB
- Bootstrap 5

### ✨ Features
- List available bikes
- Create, Read, Update, Delete bikes (Full CRUD)
- User and reservation management
- Responsive UI

### ▶️ Getting Started
```bash
git clone https://github.com/cesar2718/BicicletaMVC1.git
dotnet restore
dotnet ef database update
dotnet run





# BicicletaMVC1 - Sistema de Gestión de Bicicletas

Aplicación web desarrollada con ASP.NET Core MVC para la gestión y alquiler de bicicletas.

### 🚀 Tecnologías

- ASP.NET Core MVC
