> Full-stack e-commerce web app built with ASP.NET Core 8 MVC, following Clean Architecture principles. Portfolio project targeting Junior .NET Developer roles in London, UK.

### 🚀 Tech Stack
- **Language:** C# 12 / .NET 8
- **Framework:** ASP.NET Core 8 MVC
- **ORM:** Entity Framework Core 8
- **Database:** SQL Server / LocalDB
- **Frontend:** Razor Views, Bootstrap 5, jQuery
- **Auth:** ASP.NET Core Identity

### ✨ Features
- List available bikes with filtering
- Full CRUD operations (Create, Read, Update, Delete)
- User and reservation management
- Shopping Cart & Admin Panel
- Responsive UI - Mobile First
- Clean commit history & 100% C# codebase

# BicicletaMVC1 - Sistema de Gestión de Bicicletas

Aplicación web desarrollada con ASP.NET Core MVC para la gestión y alquiler de bicicletas.

### 🚀 Tecnologías
- C# / .NET 8
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server / LocalDB
- HTML, CSS, Bootstrap

### ✨ Funcionalidades
- Listado de bicicletas disponibles
- Alta, edición y borrado de bicicletas (CRUD)
- Gestión de usuarios y reservas
- Interfaz responsive

```bash
